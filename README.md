## 方法一：官方网页订阅

- **ChatGPT：** 定价页付款 FAQ 写"你可以使用任何主要信用卡购买 ChatGPT Go、Plus、Pro 或 Business"（10-27 核对中文版定价页）。
- **Claude：** 在 claude.ai 用银行卡订阅，以结算页显示的付款方式为准；国内发行的卡常被拒。
- **Google：** 用 Google 账号里的付款方式订阅；本文没有逐项核对 Google 接受哪些卡。
- **Grok：** x.ai/pricing 写"自助订阅支持所有主流信用卡和借记卡"（10-27 核对）。
- **优点：** 最正规，订阅、发票、退款都在官方。**缺点：** 国内卡经常付款失败，反复重试更难通过；官方价另加税，用人民币卡付外币还可能有货币转换费。

## 方法二：苹果 / 谷歌应用内购

- **怎么做：** 在 iPhone / 安卓的官方 App 里升级，用应用商店账号的付款方式或余额付款。
- **价格：** 以应用商店当地显示为准，可能和网页价不同（Anthropic 帮助中心原文写了"手机端价格可能因应用平台不同而不同"）。

- **注意：** 应用内订阅由苹果 / 谷歌管理，取消和退款都要走商店；同一个账号在网页和 App 各订一份会被重复扣费（[OpenAI：如何避免被重复扣费](https://help.openai.com/en/articles/20001043-how-do-i-avoid-being-charged-twice-if-i-subscribe-to-chatgpt-on-ios-android-and-the-web)，2026-10-26 核对）。

## 方法四：代充（第三方代付）

- **是什么：** 由第三方卖家替你付款，把会员开到**你自己的账号**上。付款人不是你，所以不能找官方退款，售后全靠卖家。
- **价格：** 卖家自己定价。以 ChatGPT Plus 一个月为例，截至 2026-10-26，其他代充平台约 ¥148～¥189。远低于官方折算价（几十块一个月）的，常见是退款单、漏洞单，过几天会被收回。
- **条件：** 有一个能正常登录的账号；靠谱的做法不要密码、不要验证码。
- **官方立场：** xAI 定价页 FAQ 写明不授权任何经销商或第三方卖家，从其他渠道购买的订阅可能被暂停或终止（10-27 核对）；OpenAI 帮助文章写明禁止共享账号凭证和转售访问权限。代充开在你自己的账号上，和"共享账号"不同，但它不是官方渠道，这个风险要自己衡量。

## 代充价怎么算账：3 步

1. **先把官方价换成人民币：** 用上面的表，例如 Plus 20 美元约 ¥133、Claude Pro 约 ¥133、Grok Premium 约 ¥200。
2. **再加上官方没算进去的钱：** 四家标价都不含税；用人民币卡付外币，银行还可能收货币转换费。所以"官方价"实际付出去的一般比表里多。
3. **最后看售后：** 同样的价格，开通失败退不退、本期内掉会员补不补、找不找得到人，差别很大。只比价格不比售后，便宜的反而可能更贵。

## 怎么判断代充靠不靠谱：6 个判断点

1. **价格是否正常：** 远低于官方折算价的要问清为什么；看清有没有"起"字，服务费、发票费是否另算。
2. **要不要账号密码：** 不应该要。要密码、要验证码、要关两步验证、要装软件的，换一家。
3. **多久到账：** 问清是自助还是人工、大概多久。
4. **失败怎么退：** 付款前问清开通失败钱怎么处理。
5. **掉会员管不管：** 质保覆盖多久、掉了怎么补，要有文字写明。
6. **售后找谁：** 有没有找得到的真人、订单查询入口，域名能不能在别处核实。
